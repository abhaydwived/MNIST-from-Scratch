#  MNIST Neural Network from Scratch (NumPy Only)

This project showcases a simple neural network built **entirely from scratch using NumPy**, without using any high-level libraries like TensorFlow or PyTorch. It is trained on the **MNIST dataset** and achieves over **90% accuracy** on digit classification.

##  Features
- Fully-connected neural network built from scratch
- Forward and backward propagation
- Softmax activation and cross-entropy loss
- Mini-batch gradient descent optimization
- Accuracy and loss visualization

##  Dataset
- **MNIST** dataset of handwritten digits (28x28 grayscale images)

##  Technologies Used
- Python
- NumPy
- Matplotlib (for visualization)

##  Results
- Achieved **90%+ test accuracy**
- Clear understanding of neural network internals and training loop mechanics
